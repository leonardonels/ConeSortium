ConeSortium,
ten ways to finish it

Redesign proofs · built from your 7 references

Each proof is a complete page with the real content: the four nodes, the pipeline, the jokes and the install command. They are directions to choose from, not final pages. Open each one at desktop and phone width.

Why the current page feels unfinished

One sheet, five times

Cover and all four subjects use the same cream card. Nothing tells you where you are, and nothing builds up.

One image

Exhibit A is the only drawing. The subjects are just rows of text, with no photo, diagram or number to anchor them.

The desk is flat

The dossier idea stops at the paper's edge. There is no folder, board or archive around it, so it reads as a template.

Four typefaces

Playfair, Special Elite, Courier Prime and Caveat all compete. The references each use one display face plus one utility face.

Which one

  1. 02 The Board has the strongest idea. The ROS graph really is a network of suspects passing things to each other, so the layout teaches the pipeline. It also keeps the codenames and the bars.
  2. 09 The Folder is the safe choice if you want to keep today's look. It fixes "unfinished" by adding the folder object and the tabs, and changes little else.
  3. 05 Systems or 08 Drawing fit best if the home page leans professional, because they read as engineering work first and as a joke second.
  4. The pieces combine well: the Board as the hero, with each suspect opening a case-file sheet from 01.
