Chapter 1 · Detection

cuCONERUSH

Turns a point cloud into cone markers without ever leaving the GPU. Asking the CPU would be embarrassing.

1.1ms · RTX 4060 Mobile
Chapter 2 · Mapping

cuCONEFUSED

EKF-SLAM. Lap 1 learns where every cone is. Lap 2 uses them to drag the odometry back to reality.

1.3ms · Orin Nano
Chapter 3 · Planning

cuCONESTELLATION

Triangulates the cone map and grows a centerline. Four backends that agree to the byte.

4backends · 0 bytes apart
Appendix · Retired

CONEPOSER

One matrix multiply, kept to show the cones in RViz or Foxglove as a ground-truth reference.

Setting up your ConeSortium

  1. Clone with submodules. Every package is a submodule, so the flag matters.
  2. Build the workspace with colcon.
  3. Put blue cones on the left and yellow cones on the right. Do not move them afterwards.
git clone --recurse-submodules \
  https://github.com/leonardonels/ConeSortium
